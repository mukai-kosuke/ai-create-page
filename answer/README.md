# 実装例は、参加者が止まったときの復帰用に使う

このディレクトリは講師用です。演習には複数の正しい実装があるため、ここにあるコードだけを正解として採点しません。

- [Basic: FAQの実装例](basic-faq.md)
- [Figma: Testimonialsの実装例](figma-testimonials.md)

参加者が止まった場合は、最初から実装例を見せず、次の順で支援します。

1. エラーと直前のプロンプトを確認する
2. Claude Codeへ調査させる追加質問を渡す
3. 変更するファイルやHTML構造だけをヒントとして出す
4. 残り時間が5分を切ったら、実装例の必要部分だけを使う

Advanced編の雛形は `workshop-assets/advanced/` にあります。
