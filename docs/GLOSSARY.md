# 用語集

教材内の用語を、講習中に使う意味へ絞って説明します。

## Claude Code

ターミナルからプロジェクトのファイルを調査し、計画、編集、コマンド実行、Git操作などを行うコーディングエージェントです。

## Plan mode

Claude Codeがコードを調査しながら、ファイル編集やコマンド実行を制限するモードです。実装前の影響調査と計画確認に使います。

## CLAUDE.md

Claude Codeへ共有するプロジェクト固有の指示です。構成、よく使うコマンド、コーディングルールなどをMarkdownで記述します。

## Rule

`.claude/rules/` に分けて置くプロジェクト指示です。デザイン実装など、特定領域の詳しいルールをルートの `CLAUDE.md` から分離できます。

## Skill

複数ステップの手順を `SKILL.md` として再利用する仕組みです。この教材では `/ui-review` でUIレビュー手順を呼びます。

## Subagent

メインの会話とは別のコンテキストで、調査やレビューを担当するエージェントです。この教材では `@agent-ui-reviewer` をコード変更しないレビュー担当として使います。

## Hook

Claude Codeの決まったイベントで、コマンドや判定処理を自動実行する仕組みです。この教材では回答終了時のStopイベントで検証を実行します。

## MCP

Model Context Protocolの略です。AIアプリケーションが外部サービスのデータや機能へ接続するための共通仕様です。この教材ではFigmaのデザイン情報をClaude Codeへ渡します。

## Figma Variable

Figmaで色、余白、角丸などの値を名前つきで管理する仕組みです。コード側のCSS Variablesと対応づけて使います。

## diff

Gitで管理している基準と、現在のファイルとの差分です。AIが変更した範囲と内容を採用前に確認するために使います。

## build

開発中のソースを配布用のファイルへ変換する処理です。この教材では `npm run build` が成功することを最低限の完了条件にします。
