# Mission 1: コードを書かせる前に、プロジェクトを説明してもらう

Claude Codeをリポジトリのルートで起動します。

```bash
claude
```

最初のプロンプトは、そのままコピーして構いません。

```text
このプロジェクトが何をするものなのか説明してください。

特に次の4点を知りたいです。
- 使用技術
- 主なディレクトリとファイルの役割
- LPのページ構成
- 開発とビルドの方法

まだコードは変更しないでください。
```

回答を読んだら、次の事実が含まれているか確認します。

- Vite、HTML、CSS、JavaScriptで構成される
- HTMLの入口は `index.html`
- CSSは `src/styles/` で役割ごとに分かれる
- FAQとTestimonialsはまだない
- `npm run dev` で開発し、`npm run build` でビルドする

回答に根拠が見えない場合は、次の質問を追加します。

```text
その説明の根拠になったファイル名を、項目ごとに示してください。
推測した部分があれば分けてください。
```

ここで覚えるのは、コードをチャットへ貼り付けなくても、Claude Codeが必要なファイルを探して説明できることです。次は、曖昧な指示と具体的な指示の差を比べます。
