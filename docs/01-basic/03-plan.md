# Mission 3: Plan modeで変更を止めたまま、実装方針を確認する

Plan modeでは、Claude Codeにコードを調査させながら、ファイル編集やコマンド実行を制限できます。大きな変更や影響範囲が読めない作業は、計画の確認から始めます。

## 1. Plan modeへ切り替える

Claude Codeで `/plan` を入力するか、`Shift+Tab` でPlan modeへ切り替えます。画面上のモード表示がPlanになったことを確認してください。

## 2. 前のMissionの依頼を送る

[Mission 2の具体的な依頼](02-prompt.md)を送ります。計画には、少なくとも次の内容が必要です。

- `index.html` にFAQセクションを追加する位置
- `src/styles/components.css` へ追加するスタイル
- JavaScriptを増やすか、HTMLの `details` / `summary` を使うか
- 既存の色、余白、角丸の再利用方針
- モバイルとキーボード操作の確認方法

この教材では、標準の `details` と `summary` を使う案が適しています。JavaScriptを増やさずに開閉とキーボード操作を実現できるためです。ただし、Claude Codeが別案を出した場合は、理由を比較して決めます。

## 3. 計画を承認して実装する

Plan modeを終了し、通常の編集ができるモードへ戻します。そのうえで依頼します。

```text
その方針で実装してください。
FAQ以外には変更を広げないでください。
実装後にnpm run buildを実行してください。
```

権限確認が表示されたら、対象ファイルとコマンドを読みます。内容が依頼の範囲内であることを確認してから許可してください。初心者講習では、権限確認を一括で無効にしません。

実装が終わっても、まだ完成とは判断しません。次のMissionで変更内容を確認します。
