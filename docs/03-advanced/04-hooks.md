# Mission 4: Stop Hookで検証を自動実行する

これまでは、作業の最後に `npm run validate` を実行するよう毎回頼みました。Hookを使うと、Claude Codeの特定イベントに合わせて決まった処理を実行できます。

```bash
npm run workshop:advanced:install -- hook
```

追加される設定を読みます。

```text
.claude/settings.json
```

この設定は、Claude Codeが回答を終えようとするStopイベントで `npm run validate` を実行します。成功すれば終了し、失敗すればエラー内容をClaude Codeへ返します。

Claude Codeを再起動し、小さな読み取り依頼で動作を確認します。

```text
現在の変更ファイルを一覧にしてください。
```

回答の終了時にHookが実行されます。確認用にターミナルから同じ処理を実行しても構いません。

```bash
npm run validate
```

## Hookは安全性と実行時間を考えて共有する

Hookはプロンプト上のお願いより確実ですが、プロジェクトを開いた人の環境でコマンドを実行します。共有前に、次を確認してください。

- リポジトリ内の安全なコマンドだけを実行する
- 外部への公開、削除、課金を伴う処理を入れない
- 毎ターン実行しても現実的な時間で終わる
- 失敗時に原因がわかる出力を返す

この教材のHookはローカルビルドとファイル検証だけを行います。Git commit、push、デプロイは自動化しません。
