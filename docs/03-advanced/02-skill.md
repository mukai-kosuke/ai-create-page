# Mission 2: UIレビューの手順をSkillとして再利用する

BasicとFigma編では、変更ファイル、デザイン、レスポンシブ、アクセシビリティ、ビルドを毎回プロンプトへ書きました。この手順を `/ui-review` として呼べるようにします。

```bash
npm run workshop:advanced:install -- skill
```

追加されるファイルは次のとおりです。

```text
.claude/skills/ui-review/SKILL.md
```

Claude CodeをAdvanced用ディレクトリの作成前から起動していた場合は、一度終了して再起動します。その後、次のコマンドを入力してください。

```text
/ui-review
```

Skillは次の順でレビューします。

1. 変更範囲を確認する
2. 要件と差分を対応づける
3. 既存デザインとの整合を確認する
4. レスポンシブとアクセシビリティを確認する
5. `npm run validate` を実行する
6. 重大度つきで結果を報告する

Skillは「常に守る短いルール」ではなく、「必要な場面で実行するまとまった手順」に向きます。次は、この手順を独立したレビュー担当へ渡します。
