# Mission 1: 毎回伝えるデザインルールをRulesへ移す

ルートの `CLAUDE.md` は、Claude Codeがセッション開始時に読むプロジェクト指示です。ビルドコマンド、構成、変更時のルールなど、プロジェクト全体で繰り返し使う短い情報を置きます。

デザイン実装のルールを分けて管理するため、雛形を導入します。

```bash
npm run workshop:advanced:install -- memory
```

追加されるファイルを読みます。

```text
.claude/rules/design.md
```

Claude Codeへ確認してください。

```text
このプロジェクトでUIを変更するときに守るルールを、根拠ファイルと一緒に説明してください。
```

## CLAUDE.mdとRulesの分け方

- リポジトリ全体の短い前提は `CLAUDE.md`
- 特定の作業領域に関する詳しいルールは `.claude/rules/`
- 個人だけのメモは共有ファイルへ混ぜない

ルールを増やしすぎると、重要な指示が埋もれます。「毎回の作業で本当に必要か」を基準に残してください。複数ステップのレビュー手順はルールではなく、次のSkillへ移します。
