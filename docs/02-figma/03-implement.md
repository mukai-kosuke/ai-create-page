# Mission 3: Figmaと既存コードの両方に根拠を置いて実装する

Planに納得できたら、実装を依頼します。

```text
作成した対応表とPlanに沿って、Testimonialsセクションを実装してください。

追加条件:
- Basicで追加したFAQがある場合は、workflowセクションとFAQセクションの間へ追加する
- 3件の引用をHTMLへ記述する
- 画像ファイルは追加せず、氏名のイニシャルをアバターとして使う
- デスクトップは3列、767px以下は1列にする
- blockquote、氏名、役割の意味がHTMLから伝わるようにする
- Testimonials以外の既存内容は変更しない
- 実装後にnpm run buildを実行する
```

Figmaにモバイルフレームがない場合、モバイル仕様は推測になります。Claude Codeが「Figmaどおり」と断定していたら、事実と判断を分けるように頼みます。

```text
実装後の説明を、Figmaから確認した事実と、このコードベース向けに判断した内容へ分けてください。
```

実装が終わったら、画面を見て終わりにせず、次のMissionで差分を確認します。
