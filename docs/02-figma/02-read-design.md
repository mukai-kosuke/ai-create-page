# Mission 2: Figmaを実装前の仕様として言語化する

対象フレームへアクセスできたら、構造と見た目を分けて調査します。

```text
このTestimonialsフレームを調査してください。
まだコードは変更しないでください。

次の順に説明してください。
1. セクションとカードの構造
2. Auto Layoutの方向、gap、padding
3. 使用しているVariablesと値
4. Typographyの階層
5. コンポーネントと繰り返し要素
6. 幅が狭くなったときに判断が必要な点

Figmaから確認できた事実と、あなたの推測を分けてください。
```

説明を[デザイン仕様](design-spec.md)と照合します。値が違う場合は、Figmaで確認できた値を優先し、講師へ差分を共有してください。

## 既存コードのルールも調べる

Figmaだけを見た実装は、このLPの命名やレスポンシブ方針から外れる可能性があります。続けて依頼します。

```text
現在のTaskFlow AIのLPも調査してください。

Testimonialsを追加する前に、次の対応表を作ってください。
- Figma Variables → 既存CSS Variables
- FigmaのAuto Layout → 既存のCSSレイアウト
- Figmaの角丸 → 既存のradius変数
- Figmaにないモバイル仕様 → このLPで採用する案

まだ実装しないでください。
```

この対応表が、Figmaの値をそのまま直書きせず、既存コードへ適応するためのPlanになります。
