# Mission 4: Figmaとの差と、コード上の問題を別々にレビューする

レビューでは「ピクセルが同じか」と「実装として適切か」を混ぜません。Claude Codeへ順に依頼します。

```text
FigmaのTestimonialsと現在の実装を比較してください。

次の表で報告してください。
- 項目
- Figmaで確認できる値
- 実装値
- 差異
- 修正が必要か

構造、余白、色、角丸、Typography、カード数を対象にしてください。
```

続けて、コードレビューを依頼します。

```text
Testimonialsの実装をコードとしてレビューしてください。

次を確認してください。
- 既存CSS Variablesの再利用
- 意味のあるHTML構造
- 幅390px前後での折り返し
- キーボード操作と読み上げ順
- 不要な依存関係や既存箇所への変更

Figmaとの差異とは分けて報告してください。
```

最後に自分でも差分とビルドを確認します。

```bash
git diff --stat
git diff
npm run build
```
